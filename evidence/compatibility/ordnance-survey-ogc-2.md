 Accessing OS APIs 
 OS Maps API
 What is OS Maps API? 
 Get started for free and integrate OS’s up-to-date, detailed maps in your apps, enabling your customers to make location-based decisions with confidence, and removing the overhead of managing complex datasets yourself.
 Choose the style that suites your use case best, whether you need the detail of OS MasterMap or our iconic Leisure maps. There are four styles available: Road, Outdoor, Light and Leisure. Each map style contains OS OpenData and Premium data layers.
 OS Maps API serves pre-rendered raster tiles and is available in two projections: British National Grid for GB data and Web Mercator which is a global coordinate system.
 You can request the maps using the Open Geospatial Consortium Web Map Tile Service ( WMTS ) standard or RESTful ZXY . WMTS is supported by most GIS software and ZXY is efficient for web mapping.
 Get this data 
 To access the OS Maps API, you need an API Key. This key will be specific to a dedicated API project linked to your OS Data Hub account.
 Click Get started to find out how to get your API Key and access OS Maps API data, or Go to the OS Data Hub where you can access the API Projects page to manage all of your OS APIs.

 Things to remember for OS Maps API 
 You can:
 Use as a basemap in GIS, web or mobile applications
 Overlay your own data to give it geographic context
 Trace over OS MasterMap Topography Layers (Premium data) detailed geometries
 View the whole of Great Britain in unrivalled, elegant detail
 Access the iconic 1:25 000 Scale Colour Raster (Premium data)
 Present mapping in different styles according to your needs
 Access the maps in different projections – British National Grid and Web Mercator
 Connect OS Maps API with your own geospatial data using the OS Power BI Map Visual 
 You can't:
 Re-style the maps as they are pre-rendered images
 Interact with the map features
 OS Power BI Map Visual 
 The OS Power BI Map Visual is a custom open source visual designed to easily display geospatial data on an OS backdrop map in Power BI dashboards; the visual can be downloaded from the Releases page of the OS GitHub repository .
 OS Maps API can be integrated with the OS Power BI Map Visual to enable you to connect geospatial data from your own organisation.
